# Втеча на каву 3D — P2P-версія

Один файл `index.html`. 3D на three.js r128 (з cdnjs), мережа та сама, що й у 2D-версії:
`createNet` з `https://iclimber.github.io/p2p-net/v1/net.js`, гра `coffee-escape-3d` (кімнати окремі від 2D).

Викладати так само: на GitHub Pages під `https://iclimber.github.io/...` (або додати свій origin на сервері сигналізації).
Кімната — хеш адреси (`.../#druzi`).

Керування: W/S — вперед/назад, A/D — убік, миша (клацни по екрану) або ←/→ — поворот, Shift — біг.
На телефоні: хрестовина зліва, огляд — вести пальцем по екрану, кнопка «БІГ» праворуч.
